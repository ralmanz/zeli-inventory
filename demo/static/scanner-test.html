Propuesta de piloto

Probarlo en un próximo inventario real con un equipo pequeño, medir cuántas excepciones aparecen y cuánto tiempo toma resolverlas.

Resumen · 60 segundos

El flujo completo, sin probar cada pantalla

1

El equipo carga el maestro del cliente

Excel/CSV con SKU, descripción y barcode. No hace falta integración directa para el piloto.

2

El equipo cuenta desde teléfonos

Scanner por cámara, scanner Bluetooth o entrada manual. Barcode + cantidad.

3

Un código problemático no frena el conteo

Cantidad + foto → excepción → siguiente producto.

4

El supervisor resuelve desde una mesa

Sugerencias, búsqueda manual y confirmación humana.

5

El sistema aprende el mapeo durante la sesión

El mismo barcode se reconoce automáticamente la próxima vez.
